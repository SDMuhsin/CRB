# Anonymous repository

This repository houses code for two papers currently under review. Each paper has its own README with the abstract, dependencies, reproduction steps, and supported configurations.

- [`docs/DOML.md`](docs/DOML.md) — Distribution-Optimal Multi-Level Quantization and Joint Sparsification for 2-Bit LLMs.
- [`docs/CRB.md`](docs/CRB.md) — Coupled Residual Binarization with Two-Way Sign Refinement: Advancing LLM Compression.

The two papers share a common quantization harness (model loaders, calibration, evaluation, sbatch drivers); per-paper run commands and method tags are listed in the corresponding README.
